NAU

The ship you live on.

Nau is the immutable, verity-protected A/B distribution that shuttle assembles from declared packages. Install is a flash of a mission image; updates ride the ground track from the download lane; rollback is simply the other slot.

03 Ground track

Docs & lanes

Everything below is a static tree served read-only — no accounts, no API, no state. Three lanes under nau.rclb.dev, one assembler repo.

  • Repo rbelem/shuttle The assembler. shuttle builds Nau from Lua declarations — a programmable replacement for Snapcraft's YAML. GPL-3.0-only, Linux-only.
  • ADR-0013 Brand rules The rename record: why Nau, how missions are named, and the per-language pronunciation matrix this page mirrors.
  • ADR-0044 Flight rules The install path: mission images, the dd flash, and verify-image. Install copies bytes; it never signs or re-lays-out.
  • Lane · download download.nau.rclb.dev Mission images, SHA256SUMS, and the signed image manifest. Install and update share one tree, one domain, one certificate.
  • Lane · cache cache.nau.rclb.dev The public package mirror of the released pool — what shuttle pull and Nau pods consume, with a freshness stamp per publish.
